# Documentation map

OpenModalityTrust is the umbrella and shared local verifier. Begin with the
[project case](../README.md); use this map to choose the next file.

| Goal | Read |
|---|---|
| Understand the problem and try demos | [README](../README.md) |
| Learn the vocabulary | [Glossary](glossary.md) |
| Find code and its owning repository | [Code map](code-map.md) |
| Install or change a checkout | [Development workflow](development.md) |
| Understand trust/enforcement boundaries | [Architecture](architecture.md), [threat model](threat-model.md) |
| Use the implemented signing/action profile | [Core guide](../core/README.md), [local profile](../spec/local-profile.md) |
| Study future common contracts | [Draft specifications](../spec/README.md), [adapter contract](../spec/adapter-contract.md) |
| Check measured results and manuscripts | [Evidence index](../research/README.md) |

| Work as a coding agent | [Agent guide](../AGENTS.md), [core instructions](../core/AGENTS.md) |

Each pinned modality has its own README, documentation map, Makefile and agent
instructions. OpenAVT's protected voice transport is independent. OpenAST/OpenATT
use the shared local profile; a common project name does not imply cross-modal
wire compatibility or a general composition guarantee.
