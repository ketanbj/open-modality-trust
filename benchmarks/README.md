# Measured local benchmarks and future scope

See the [evidence index](../research/README.md) and each modality's
`docs/benchmarks/README.md` for measured counts, exact commands, raw reports,
source-hash checks and negative results. OpenAST measures generated QR rasters;
OpenATT measures generated force traces. Policy cases enter after modality parsing;
the end-to-end demos exercise the combined path. The typed-policy control matches
serial decisions. No superiority over equally expressive authorization is shown.

Future work measures physical channels, unsupported-guarantee acceptance,
unauthorized participating-backend effects, leaks across all enabled agent outputs,
benign completion, interventions, exchanges and delay. Use paired tasks, held-out
attacks, strong IFC/authorization controls and explicit effect semantics. Transport
failure alone is not a successful authorization defense.
