# Benchmark plan

Measure unsupported guarantee acceptance, unauthorized backend effects, leaks
through enabled outputs, benign task completion, interventions, exchanges/bytes,
latency and verifier cost. Rejections caused by transport failure are not evidence
of correct authorization. Include equally expressive IFC and transactional
controls, not only an undefended agent.

Compare scripted protocol cases with model-driven tasks. Use held-out attacks,
paired task configurations and explicit channel conditions. Camera/display,
acoustic and tactile fixture results are future work; see the evidence index
for existing local voice measurements.
